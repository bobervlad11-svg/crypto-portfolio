# Crypto Portfolio

Скрипт на Python, который хранит криптовалютный портфель и показывает его текущую стоимость.

## Что умеет

- Хранит количество монет в файле `portfolio.json`
- Получает текущие цены любых монет из портфеля через CoinGecko API
- Показывает цену, количество и стоимость каждой позиции, а также общую стоимость портфеля
- Пропускает монету, если API не вернул цену
- Принимает количество с запятой (`0,5`)
- Отклоняет слова, ноль и отрицательные числа

## Как запустить

1. Установить Python 3 и библиотеку requests:
   `pip install requests`
2. Запустить скрипт:
   `python portfolio.py`
3. После запуска появится меню: нужный пункт выбирается цифрой

## Пример работы

```
Добавить монету - 1
Показать портфель - 2
Выйти - 3
Выберите: 2
bitcoin: 0.5 x $64929 = $32464.5
ethereum: 0.5 x $1824.92 = $912.46
Всего: $33376.96
```

## Технологии
